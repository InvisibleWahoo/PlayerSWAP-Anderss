Este es un Datapack el cual está hecho para la 1.21.1.
Cómo funciona
Cada 5 minutos mezcla en orden aleatorio a todos los jugadores (menos espectadores) y cada uno va a la posición del siguiente. Como es un ciclo, nadie se queda en su lugar.
Los últimos 10 segundos aparece la cuenta regresiva en la action bar.
Cada jugador recibe un mensaje con el nombre de quien estaba antes donde apareció.
Con menos de 2 jugadores avisa y no hace nada.
Funciona entre dimensiones.

Comandos (necesitás ser operador)
/function swap:do_swap: fuerza una rotación ahora.
/function swap:stop: detiene el temporizador.
/function swap:init: lo reinicia desde 5 minutos.
Cambiar el tiempo
